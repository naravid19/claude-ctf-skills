# ADR 0002: Catalog UI & Documentation Architecture

## Status
Accepted

## Date
2026-09-27

## Context
The repository publishes a public static web catalog at `https://naravid19.github.io/claude-ctf-skills/` via GitHub Actions (`pages.yml`). 
Previously, the catalog generated by `scripts/generate_catalog.py` was a plain, unsearchable card grid that only tracked markdown technique files and omitted skill-scoped exploit scripts (`skills/ctf-pwn/scripts/*`, `skills/ctf-web/scripts/*`). Furthermore, `README.md` was a concise overview that lacked comprehensive architecture diagrams, toolchain setup details, and explication of new exploit generator scripts.

Users navigating CTF skills during competitions require:
1. Fast, client-side, zero-dependency instant search across skills, techniques, and exploit scripts.
2. Filter pills by domain category (Web, Pwn, Crypto, Reverse, Forensics, Misc, AI/ML, Malware, OSINT, Orchestrators).
3. Explicit discovery of executable exploit templates and fuzzers.
4. A high-contrast "Terminal Cyber Dark" aesthetic matching professional offensive security tooling.
5. In-depth repository documentation covering setup, architecture, verification, and offline usage.

## Decision
1. **Catalog Generator Redesign**:
   - Modernize `scripts/generate_catalog.py` to scan both `*.md` technique files and `scripts/*.py` skill helpers.
   - Implement a responsive "Terminal Cyber Dark" UI theme with Zinc-950/Zinc-900 palettes, high-contrast monospace accents (Cyan `#06b6d4`, Emerald `#10b981`), and zero external framework dependencies (pure static HTML/CSS/JS).
   - Embed lightweight client-side live search and category filtering with instant match counters.
   - Provide a 1-click clipboard copy widget for `/plugin marketplace add naravid19/claude-ctf-skills`.
   - Maintain GitHub URL link resolution pointing to `skills/<skill>/<technique>` to preserve test compliance (`test_catalog_links.py`).
2. **README Documentation Overhaul**:
   - Structure `README.md` according to comprehensive documentation standards: Architecture diagrams (Mermaid), deep toolchain guides (Unicorn, Capstone, fpylll, gmpy2), and testing/audit instructions.

## Consequences
- **Positive**: Instant technique and script lookup on mobile and desktop during CTFs.
- **Positive**: 100% static, fast, self-contained single-page application deployed automatically on push to `main`.
- **Positive**: Exploit scripts are first-class citizens in both catalog and README.
- **Trade-off**: `generate_catalog.py` must maintain the custom `skills/` path logic to avoid 404 links on GitHub Pages.
